# Web-Design-Project
This is my first github Project..
📘 Project Overview

This is a fully functional college website project created as part of an academic assignment. The website represents Katihar Engineering College, showcasing its departments, facilities, placements, academic structure, and more.
It is built using HTML, CSS, and JavaScript, and designed to be clean, responsive, and user-friendly.

🌐 Features

🏠 Home Page with college introduction and image carousel

🏢 About Page — Vision, Mission, and Institutional Overview

📚 Academics Section — Courses, Curriculum, and Departments

🧑‍🏫 Departments Page — Branch-specific information

🏗️ Facilities Page — Library, Hostel, Labs, and Infrastructure

🎓 Placements Page — Career and recruitment details

🪪 Approvals Page — AICTE and government recognitions

📜 RTI and Notices Section — Scrolling student notifications and BEU result updates

🖼️ Gallery Page — Campus photos

📞 Contact Page — Communication details and Google Map embed

📸 Responsive Carousel — Auto-fading image slider using JS

🔝 Back to Top Button and smooth navigation

🎥 Optional Video Section showcasing campus life

💻 Technologies Used

HTML5 — Page structure and content

CSS3 — Styling and responsive layout

JavaScript (Vanilla JS) — Carousel, scrolling effects, and interactivity
